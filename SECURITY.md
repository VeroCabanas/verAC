# Seguridad y comunicación de incidencias

No incluya archivos `.bin`, resultados, códigos de participante ni otros datos de investigación en una incidencia pública de GitHub.

Para comunicar un posible problema de seguridad o privacidad, contacte de forma privada con la autora en `veronica.cabanas@uam.es` e indique únicamente la información técnica imprescindible. No adjunte datos reales hasta acordar un canal autorizado.
