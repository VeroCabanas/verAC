# Componentes de terceros

El código propio de verAC se distribuye con licencia MIT. El paquete autónomo para Windows incorpora software de terceros que mantiene su autoría y licencia originales.

## Componentes principales

- **R 4.6.1** — GPL-2.0-or-later / GPL-3.0-or-later, con algunos componentes bajo LGPL u otras licencias compatibles. Sitio oficial: <https://www.r-project.org/>.
- **GGIRread 1.0.8** — Apache-2.0. Sitio: <https://cran.r-project.org/package=GGIRread>.
- **data.table 1.18.4** — MPL-2.0. Sitio: <https://cran.r-project.org/package=data.table>.
- **openxlsx 4.2.8.1** — MIT. Sitio: <https://cran.r-project.org/package=openxlsx>.
- **webshot2 0.1.2** — MIT; solo se utiliza para la conversión opcional de HTML a PDF. Sitio: <https://cran.r-project.org/package=webshot2>.

La relación completa de versiones y licencias se encuentra en [`dependency-manifest.csv`](dependency-manifest.csv).

## Distribución del paquete autónomo

La futura *release* deberá conservar los archivos de licencia suministrados por R y por cada paquete. También se publicará, junto al paquete binario autónomo, un archivo con las fuentes correspondientes o instrucciones suficientes para obtener exactamente las versiones redistribuidas, de acuerdo con sus licencias.

Este documento es un inventario técnico y no constituye asesoramiento jurídico.
