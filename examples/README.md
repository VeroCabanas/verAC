# Ejemplos

Este directorio no contiene datos de participantes. Los dos registros breves autorizados para la autocomprobación se encuentran en `scripts/arch_prueba` porque el instalador los necesita en esa ubicación.

No utilice este directorio para almacenar archivos reales: las demostraciones adicionales deberán ser sintéticas o haber sido creadas expresamente para su difusión.
